# 🎵 Spotify Clone - Full Stack Music Streaming Platform

**Spotify Clone** is a modern, full-stack music streaming application inspired by Spotify's user experience. Built using **React, Node.js, Express.js, MongoDB, Cloudinary, and Tailwind CSS**, the project features a fully responsive music player along with a dedicated **Admin Dashboard** for managing albums and songs. Administrators can upload album covers, song thumbnails, audio files, select custom album gradient colors, and manage the entire music library, while listeners can browse albums, play songs, and enjoy a clean Spotify-inspired interface.

# ✨ Key Features

## 🎧 For Listeners

* Browse all available albums
* Browse featured songs
* Play and pause music
* Previous & next song controls
* Dynamic music progress bar
* Album-wise song listing
* Beautiful Spotify-inspired UI
* Dynamic album gradient backgrounds
* Responsive design for desktop, tablet, and mobile
* Fast and smooth music playback

---

## 👨‍💼 Admin Dashboard Features

* Upload new albums
* Upload album cover images
* Select custom album gradient colors
* Upload new songs
* Upload song thumbnails
* Upload audio files
* Delete albums
* Delete songs
* Manage complete music library
* Cloudinary media integration
